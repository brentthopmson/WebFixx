Connect this device to WebFixx Graph

WebFixx Graph indexes metadata of files in your approved folders so you can search and retrieve them remotely. One-time index dump, then periodic polling. No inbound ports.

Scope disclosure
  • What is indexed: file path, name, size, modified time, mime type (metadata only).
  • Approved roots: you choose during install (default: Documents, Desktop, Downloads).
  • Retention: until you revoke. Revoke anytime from the WebFixx app.
  • File bytes are never uploaded unless you explicitly request a transfer from the launcher.
